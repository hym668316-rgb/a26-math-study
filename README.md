# 高等工程数学A26 · 递进学习系统

矩阵论 + 数值计算引论 + 数值积分与微分 的交互式学习网页。

## 内容

- **18 个知识点**，按「核心 ★★★ / 重点 ★★☆ / 了解 ★☆☆」三级分层
- **96 条例题**，按重要程度配比（核心 6 例 / 重点 4 例 / 了解 2 例）
- 递进学习路径、习题系统、互动问答
- 各知识点掌握度扇形图 + 总体掌握度 + 复习学习时间折线
- 前后知识点依赖可跳转

## 特点

- 学习进度存在**浏览器 localStorage**，不上传任何数据
- 公式在构建期预渲染为 **MathML**，不加载任何数学运行时
- 图表用 ECharts 本地内嵌，无外部 CDN 依赖
- 手机窄屏已适配（≤560px 无横向溢出）

## 打开

本站为 GitHub Pages 静态站，直接访问首页即可，无需安装任何东西。
建议在手机浏览器里用「添加到主屏幕」当应用使用。
